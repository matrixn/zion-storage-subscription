# Home illustration carousel

The existing home illustration now has two server-rendered scenes in RO/EN/FR/DE: the original mobile backup animation and an illustrative shared-storage versus dedicated-media comparison. `templates/hero-backup.php` retains the original illustration; `templates/hero-carousel.php` adds the comparison and controls. Its Personal name/capacity comes from the recommended plan in `config/plans.php`. The example is the same 100 GB / 65 media / 20 files / 15 email allocation used below pricing. It is labelled illustrative, not a user's statistics or an official provider performance claim. No Google logos or affiliation are implied.

Google Photos is the consumer service being compared, not the separate Google Cloud infrastructure product. Google documents shared capacity across Photos, Drive and Gmail in [How your Google storage works](https://support.google.com/accounts/answer/9312312?hl=en). The illustration does not assert that every user has the example allocation. Zion's shown capacity is reserved for photos/videos; no comparative encryption or shared-family-account claim is added.

`public/assets/hero-carousel.js` rotates every four seconds while visible. Hovering either the site header or the slider pauses rotation and the subtle two-pixel progress bar; leaving resumes the remaining time. There is no play/pause button. Arrows, scene buttons, left/right keys and horizontal touch swipes provide manual navigation. Keyboard focus, offscreen state and hidden tabs suspend timers. Reduced motion disables automatic rotation and transitions. Decorative backup animation pauses along with rotation. Automatic changes do not announce through a live region; manual changes do. Hidden scenes use native hidden attributes.

`public/assets/hero-carousel.css` keeps a fixed scene viewport at each breakpoint so automatic changes do not move the surrounding page. Controls stay outside scaled artwork with comfortable touch sizes. Home alone loads these assets. Without JavaScript the original illustration remains available, inactive controls stay hidden, and the full comparison remains accessible in pricing below.

Validation covers all four locales at eight viewport sizes, scene fit, stable layout, keyboard/swipe, four-second rotation, header/slider hover, preserved elapsed progress, offscreen suspension, reduced motion and no-JavaScript fallback. Ignored screenshots are tests/artifacts/hero-backup-*.png and hero-comparison-*.png.

Run `node tests/hero-carousel-browser.cjs` with Playwright/Chrome and the local PHP server. Optional environment settings: PLAYWRIGHT_MODULE, BROWSER_CHANNEL, TEST_URL. Pricing, signup, billing and invoice flows are unchanged.
