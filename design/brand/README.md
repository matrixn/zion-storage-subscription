# Zion Storage icon

Generated with the built-in ImageGen tool on 18 October 2026. `zion-icon-master.png` is the 1024×1024 raster master. The icon deliberately combines stacked photograph frames with a mountain silhouette, lime green and a charcoal background. It contains no text, so the same mark is used in RO/EN/FR/DE.

Generation brief:

> Premium square app icon for Zion Storage, a private mobile photo/video backup service. Deep charcoal #0b1115 background; bold lime #c4f582 emblem of layered photograph frames, with mountain peaks in negative space. Elegant rounded geometry, generous clear space, subtle depth and edge lighting; readable at 24px. No text, watermark, external shadow, generic cloud, padlock, camera lens, rainbow or chrome. Opaque full-bleed square suitable for operating-system masking.

Export sizes: `public/assets/icon.png` 256px for site imagery, `app-icon.png` 512px, `apple-touch-icon.png` 180px, `favicon-32.png` and `favicon-16.png`, plus `favicon.ico` with 16/32/48px entries. Standard Lanczos resizing and PNG compression were used. `icon.svg` is a legacy-compatible SVG wrapper containing the new PNG, not a vector redraw. `og.svg` retains the existing share-card layout with the new embedded icon; `og.png` is its 1200×630 raster export.

Keep icon exports square and derive replacements from the master, avoiding repeated resizing of smaller files. The generated original also remains in the local Codex generated-images directory; production assets do not depend on that directory or external image hosting.
